# Student Fitness Profile System

A web system for Bulacan State University that lets PE students record fitness
test results and track their progress, and lets teachers review class-wide
fitness analytics.

Students take a pre-test (BMI, VO2 max, and five skill-based assessments:
flexibility, strength, agility, speed, endurance), then retake it as a
post-test later in the term. The dashboard charts pre-test versus post-test
results. Teachers can browse all students, open any student's progress page,
and view class averages filtered by section, program, date range, and test
type.

## What is inside

- Student login and sign-up, teacher login
- Pre-test and post-test forms with live BMI and VO2 max calculators
- Progress dashboard with Chart.js bar and radar charts
- Remarks history with pagination (logins, logouts, tests taken, password
  changes)
- Change password with live validation
- Teacher side: student list with search and sorting, class analytics with
  filters

## Tech

- PHP 8 (no framework)
- MySQL / MariaDB via mysqli, prepared statements
- jQuery, Chart.js
- Runs on XAMPP

## How to run

1. Install XAMPP and start Apache and MySQL.
2. Copy this folder into `C:\xampp\htdocs\`.
3. Create the database: open phpMyAdmin (http://localhost/phpmyadmin), create a
   database named `student_health`, then import `database_schema.sql`.
4. Create at least one teacher account, since teacher accounts are not created
   through the UI. In phpMyAdmin run:

   ```sql
   INSERT INTO `user` (`user_id`, `password`, `role`) VALUES
   ('USER-0001', '<paste a bcrypt hash of your password>', 'ROLE-0002');

   INSERT INTO `teacher` (`teacher_id`, `user_id`, `first_name`, `last_name`)
   VALUES ('T-0001', 'USER-0001', 'John', 'Doe');
   ```

   To generate the hash, run `echo password_hash('yourpassword', PASSWORD_DEFAULT);`
   in a PHP file, or use any bcrypt generator.
5. Open http://localhost/WST%20Project/ and sign up as a student, or log in as
   the teacher created above.

The app connects as localhost root with no password, matching a default XAMPP
install. If your MySQL root has a password, set it in `database_conn.php`.

## Folders

- `css/` - stylesheets (shared and per-page)
- `js/` - all scripts, student and teacher
- `teacherSide/` - teacher pages
- `image/` - static images
- `database_conn.php` - single database connection used everywhere
- `database_schema.sql` - schema, triggers, and reference seed data

## Notes

- IDs such as `USER-0035` and `ST-0032` are generated by database triggers.
- Passwords are stored as bcrypt hashes.
- Session checks guard every student and teacher page.
